1️⃣ Quick Recap 🧰

🍪 Analogy: A class is a cookie cutter. An object is a real cookie.
  • class Box { ... }; – blueprint (don't forget ;). public: = anyone can use it.
  • Box b; makes an object. b.length – dot means "of b".
  • A member function is a function inside the class. void = gives nothing back; return sends a value back. (int x) = a value we hand in.
  • cout << length << " "; prints a number, then a space. * multiplies.
  • for (int i = 0; i < 3; i++) = repeat with i = 0, 1, 2 (i++ adds 1).

2️⃣ Constructor 🏭

📱 Analogy: When you buy a new phone it already has factory settings. You didn't press anything. A constructor sets up a new object automatically.
  • A constructor is a special member function that runs by itself the moment an object is made.
  • Its name is the same as the class. It has no return type (not even void).
  • A constructor with no parameters is the default constructor.

3️⃣ Parameterized Constructor 🍕

🍕 Analogy: A default pizza has fixed toppings. But you can order exactly the toppings you want. A parameterized constructor lets you choose the starting values.
  • A constructor with parameters: Box(int l, int w).
  • We give the values when making the object: Box b(5, 3);

4️⃣ Constructor Overloading ☕

☕ Analogy: At a coffee shop you say "coffee". You can say just "coffee", or "coffee, large", or "coffee, large, no sugar". Same word, different details, and the shop knows what to do.
  • Many constructors in one class, all with the same name but different parameters.
  • C++ picks the one that matches the number (or type) of values you give.

5️⃣ Copy Constructor 📄

📄 Analogy: A photocopier. You put in an original and get a new sheet with the same writing. A copy constructor makes a new object from an existing object.
  • Its parameter is an object of the same class: Box(Box &o). The & means "look at the original itself".
  • Use it like this: Box b2(b1); – b2 is a copy of b1.
  • The copy is separate. Changing b1 later does not change b2.

6️⃣ Dynamic Constructor 🎭

🎭 Analogy: A theatre reserves seats after you tell them how many guests are coming. Not too few, not too many. A dynamic constructor grabs memory while the program runs.
  • Pointer: int *p; is a box that holds the address (house number) of other boxes.
  • p = new int[n]; asks for n int boxes at run time. Use them like an array: p[0], p[1]…
  • delete[] p; gives the boxes back.
  • Destructor ~Marks(): runs by itself when the object dies. It has a ~, the class name and no parameters. We use it to delete[].
  • A dynamic constructor is a constructor that uses new.

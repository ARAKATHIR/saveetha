1. What is the OOP paradigm?

A paradigm is just a style of thinking about how to write programs.

Procedural style

Think: a recipe. A list of steps (functions) run one after another. Data floats around separately. Example: C.

Object-oriented style

Think: real-world things. Bundle data and the actions on that data into one unit called an object. Example: C++.

Why use OOP? Code is organised, reusable, easier to fix, and safer, because data is protected inside objects. Big programs stay manageable.

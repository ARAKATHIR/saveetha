5Implicit Conversions

💰 Add coins and notes: you count everything in the bigger kind of money. C++ also quietly changes types by itself. This is implicit (automatic) conversion.
  • int with double → answer is double.
  • int / int → answer is int (decimal part is chopped!).
  • char in maths → becomes its number code ('A' is 65).
  • double into int → decimal part is cut off (no rounding).

3Virtual Function ✨

A virtual function is a function in the base class marked with the word virtual. It tells C++: "Check the real object, then run its own version."

💬 Analogy: You shout "Say hi!" to a group. Raj says "Hello", Meena says "Vanakkam". Same shout, but the real person decides the reply.

4Runtime Polymorphism 🎭

Poly = many, morph = forms. Runtime = decided while the program is running. So: one call, many results.

🎵 Analogy: One "Play" button. On a music app it plays a song, on a video app it plays a movie. Same button, different result.

You need 3 things: ① a base class pointer, ② a virtual function, ③ children that override it.

5Pure Virtual Function 📝

A pure virtual function has no body. We write = 0. A class with one is an abstract class: you cannot make an object from it, but you can have a pointer to it. Every child must write the function.

📄 Analogy: A worksheet with a blank: "Draw your shape: ____". The blank sheet can't be used itself. Every student must fill it in.

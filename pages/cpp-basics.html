1. Tokens

A token is the smallest meaningful piece of a program, like a word in a sentence.

The 5 kinds: Keywords, Identifiers, Constants (literals), Operators, Punctuators (like ; , { }).

🧪 Try it: type a line of C++ and see its tokens.

2. Keywords

Reserved words with a fixed meaning. You cannot use them as names. C++ has about 95. Tap one!

Tap a keyword…

3. Identifiers

Names you give to variables, functions, classes.

Rules: letters, digits, underscore only · cannot start with a digit · no spaces or symbols · no keywords · case-sensitive (Age ≠ age).

🧪 Checker: is this name valid?

4. Constants

Values that do not change.

Literals (fixed values written in code)
25        // integer
3.14      // floating
'A'       // character
"Hello"   // string
true      // boolean
Named constants
const float PI = 3.14;
#define MAX 100
// PI = 3;  ❌ error!

7. Quick Preview: Tools Used in Programs

The programs below use a few things you will study fully later. Here is a simple first look, so nothing feels strange. 🙂

🧱 Parts of a C++ program (tap a line)
Tap any line to see what it does.
⌨️ cin and cout
cout << "Hi";  // show
cin >> age;    // read

cout shows output on the screen. cin takes input from the keyboard. The arrows point where the data flows.

➕ Operators
+  add        -  subtract
*  multiply   /  divide
%  remainder  =  store value
== equal?     >  greater?

7 % 2 gives 1 (remainder).

🔀 if / else: making a decision
if (n % 2 == 0)
  cout << "Even";   // if true
else
  cout << "Odd";    // otherwise

Like real life: if it rains, take an umbrella, else don't.

🔁 for loop: repeat work
for (int i = 1; i <= 5; i++)
  sum = sum + i;

3 parts inside the brackets: start (int i = 1), keep going while (i <= 5), step (i++ means add 1 to i). 🧪 Run it one round at a time:

sum = 0. Press Next round.

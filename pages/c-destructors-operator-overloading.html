1️⃣ Quick Recap 🧰

🍪 Analogy: A class is a cookie cutter. An object is a real cookie.
  • class Num { ... }; is the blueprint. public: = anyone can use it. Make an object: Num a(5);
  • A constructor has the class name, no return type, and runs by itself when the object is made.
  • A member function belongs to the class: a.show(); (dot = "of a"). void = gives nothing back. return sends a value back.
  • cout << n; prints. Words in "quotes" print as they are.

2️⃣ Destructors 🧹

🏪 Analogy: A shopkeeper opens the shop (constructor) and, when leaving, switches off the lights and locks up (destructor). Nobody has to remind them.
  • A destructor is a special function that runs by itself when an object dies (for example when main() ends).
  • Name: ~ + class name, like ~Demo().
  • It has no parameters and no return type. A class has only one.
  • It is used for clean-up, like giving memory back.

2.1 Order of dying

🥞 Analogy: A stack of plates. The plate put on last is taken off first. Objects die in the reverse order of creation.

3️⃣ Defining Operator Overloading 🎛️

🎛️ Analogy: The + button on a TV remote raises volume. On an AC remote the same button raises temperature. Same button, different meaning depending on the device. Operator overloading gives an operator like + a new meaning for our own class.
  • An operator is a symbol like +, -, >, ++. We know 2 + 3 works for numbers.
  • But a + b for two Num objects? C++ doesn't know what we want. So we tell it.
  • We write a function with the special name operator + the symbol, e.g. operator+.
  • a + b is then just a shortcut for a.operator+(b).
  • Operands = the things the operator works on. Left one (a) is the object calling; right one (b) is the parameter.

4️⃣ Overloading Operators 🔧

4.1 Binary operator: +

A binary operator has two operands (a + b). The function takes one parameter (the right side). It gives back a new Num, so its type is Num. Since a + b is a Num, we can write (a + b).show().

4.2 Comparing: >

5 > 3 is true, which C++ shows as 1. False shows as 0. Our function returns an int (1 or 0).

4.3 Unary operator: ++

A unary operator has one operand (++a). The function takes no parameter, because the object itself is the operand. n = n + 1; adds one.

5️⃣ Rules for Overloading Operators 📜

🚦 Analogy: Games have rules. You can invent new moves, but you can't break the rules of the game.
  1. Only existing operators can be overloaded. You can't invent a new one like **.
  2. These cannot be overloaded: ::   .   ?:   sizeof
  3. You can't change the number of operands: binary stays binary, unary stays unary.
  4. You can't change precedence (which operator goes first, like * before +).
  5. At least one operand must be an object of our class. You can't change 2 + 3.
  6. As a member function: binary takes 1 parameter, unary takes 0.
  7. Keep the meaning sensible: + should add, not subtract!

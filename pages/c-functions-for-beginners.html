5Return by Reference 🔑

🔑 Analogy: Return by value gives you a copy of a house key. Return by reference gives you the real key, so you can open the real house and change things inside.

Write & after the return type: int&. The function hands back the variable itself, so you can put a new value into it.

Never return a reference to a variable created inside the function. It disappears when the function ends, like a key to a house that was demolished!

6Inline Functions ⚡

🗣️ Analogy: Instead of walking to another room to ask a tiny question, you say the short answer right here. Saves a trip!

Normally a call jumps to the function and comes back. With inline, the compiler may paste the tiny code right where it is used. Best for very short functions.

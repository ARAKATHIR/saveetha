1️⃣ Quick Recap 🧰

🍪 Analogy: A class is a cookie cutter. An object is a real cookie.
  • class = blueprint, ends with };   public: = anyone can use. private: = only the class (and its friends!) can use.
  • Make an object: Student s; Use a member with a dot: s.roll
  • A member function is a function inside the class. void = gives nothing back. (int r) = a value we hand in.
  • cout << roll << " "; prints the number, then a space. Words in "quotes" print as they are.

2️⃣ Arrays of Objects 🗄️

2.1 First, an array of numbers

🥚 Analogy: An egg tray with 3 slots numbered 0, 1, 2. Counting starts at 0!
  • int m[3]; = 3 slots: m[0], m[1], m[2].
  • for loop: for (int i = 0; i < 3; i++) = "start i at 0, go on while i is less than 3, add 1 (i++) each round".

2.2 Now, an array of objects

🔐 Analogy: A row of school lockers. Every locker is the same type and holds one student card. Locker numbers also start at 0.
  • Student s[3]; makes 3 Student objects in one go: s[0], s[1], s[2].
  • Use a member of one object: s[1].roll. Call its function: s[1].show();
  • All objects in the array must be of the same class.
  • A loop lets us handle every object with little code. * means multiply.

3️⃣ Friendly Functions 🤝

3.1 What is a friend function?

🏠 Analogy: Your house has a locked room (private data). Strangers can't enter. But you, the owner, can give your trusted friend a key. A friend function is that friend: not a family member (not a member function), yet allowed inside.
  • The class gives permission by writing friend inside the class.
  • It is not a member. We write it outside, with no ClassName::.
  • We call it without a dot: area(b), not b.area().
  • The object comes in as a parameter: int area(Box b) means "hand me a Box named b". Inside, b.length works even though length is private.

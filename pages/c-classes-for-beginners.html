Words you need first:

  • cout << – prints on the screen. Words go in "quotes".
  • main() – where the program starts.
  • Every instruction ends with ;

2️⃣ Specifying a Class 📐

🍪 Analogy: A class is a cookie cutter (blueprint). An object is a real cookie made with it. One cutter → many cookies.
  • class Box { ... }; – the blueprint. Don't forget the ; at the end!
  • Things inside are members. Variables inside are data members.
  • public: means "anyone can use these".
  • Box b; makes an object. b.length – the dot means "of b".

3️⃣ Member Functions in Detail ⚙️

📺 Analogy: A TV (object) has buttons on the remote (member functions). You press a button; the hidden wires inside (private data) do the work.

3.1 Inside the class

  • private: – hidden from outside. Only the class's own functions can touch it.
  • void – the function gives nothing back. int – it gives back a number using return.
  • (int l, int w) – values we hand to the function (parameters).
🤔 Tap: why hide data with private?So nobody can put silly values (like a length of -5) by mistake. They must use our function. Like a TV: you don't open it; you press buttons.

3.2 Outside the class

Write only the name inside the class. Write the body outside using ClassName:: (the :: says "this function belongs to Box").

4️⃣ Arrays within a Class 🥚

🥚 Analogy: An egg tray with 3 slots numbered 0, 1, 2 (counting starts at 0!). One tray name, many slots.
  • int marks[3]; – 3 int slots: marks[0], marks[1], marks[2].
  • for loop: for (int i = 0; i < 3; i++) = "start i at 0, repeat while i is less than 3, add 1 to i each time". i++ means add 1.
  • sum = sum + marks[i]; adds each slot into sum. sum is a local helper box that lives only inside the function.

5️⃣ Static Member Functions 📋

📋 Analogy: A class has one attendance register on the wall. Every student writes in the same register. That register is static. Each student still has their own bag (normal data).
  • static int count; – only one copy, shared by all objects. Set its start value outside: int Student::count = 0;
  • static void showCount() – a function that belongs to the class, not to one object. Call it with Student::showCount(); – no object needed.
  • A static function can use only static members (it doesn't know any one student's bag).

🚨 C++ Exception Handling

Throw • Catch • Rethrow • Specify — explained very simply

1️⃣ Quick refresher (tools we will use)

Only these tiny things appear in our examples:

  • cout – prints on screen. cin – reads what you type. endl – goes to a new line.
  • int – a whole number box. if – asks a yes/no question.
  • function – a small named job (like void inner()) that main can call.
🍳 Analogy: a function is like a recipe card. You call its name and it does the steps.

2️⃣ What is an exception?

An exception is a problem that happens while the program is running, like dividing by zero. Exception handling means we plan what to do when it happens, so the program does not crash.

🛞 Analogy: You ride a bike to school and the tyre gets a puncture. A smart rider keeps a repair kit, so the day is not ruined.

3️⃣ The mechanism: try → throw → catch

🧪 try

🚨 throw

4️⃣ Throwing an exception

We use the word throw followed by a value (like throw 10;). The value tells the catcher what went wrong. Tap any line, or press Next step.

Output: Before throw ⏎ Caught: 10
🔔 Analogy: throw is pulling a fire alarm. Everything normal stops at once.

5️⃣ Catching an exception

catch(int e) catches a thrown int. It must come right after the try block. If no catch matches the type, the program stops (crashes).

6️⃣ Many catch blocks and catch(...)

One try can have many catch blocks, each for a different type. catch(...) (three dots) catches anything. Put it last.

7️⃣ Rethrowing an exception

Sometimes a catch handles a little, then passes the same exception upward using throw; (no value). The caller can then catch it too. Press Next step to follow it.

Output: inner caught 7 ⏎ main caught 7
👷 Analogy: a junior mechanic looks at the bike, writes a note, and passes it to the senior mechanic.

8️⃣ Specifying exceptions

A function can announce which exceptions it may throw. throw(int) after the name means "I may throw only an int". noexcept means "I will throw nothing".

Output: Bad number -1 ⏎ I never throw
💊 Analogy: a medicine label lists its side effects, so you know what to expect.

⚠️ Note: throw(int) is the old style from many textbooks. Newer C++ (C++17) removed it, so use an older setting like C++11 to run it. noexcept works everywhere.
